음성과학 근거(SOVT·파사지오·성종 분류·MPT 규범) 대조 + 실측 검증 상태

## 시중 앱 대비 강점 (독보적)
1. **성종 추정 + 개인 파사지오 연동**: 측정 음역으로 성종을 추정하고 그 파사지오 구간을 3주차 루틴이 직접 타겟 — Singing Carrots도 음역 테스트는 있지만 루틴과 연결하지 않음
2. **메사 디 보체 + RMS 실시간 피드백**: Sing Sharp의 Messa di Voce 훈련과 dB 미터의 결합 — 2026-09 검색 기준 시장 공백
3. **성대 보호 장치의 완전성**: 목 상태 '아픔' → 루틴 강제 전환 + 토큰 멱등 정산 + 쿨다운 내장
4. **검증 깊이**: macOS CI 120 테스트(파이프라인 실측 6 포함)·9 파리티 게이트(그중 3종은 JS 이중 구현을 동일 합성 벡터로 실행 교차 검증)·시뮬레이터 스모크·가짜 마이크 E2E·UI E2E 35축 — 상용 앱 중 이 수준의 공개 검증은 없음

## 결론
**초보자 개인 연습 도구로는 최상급(A)**. 곡 라이브러리가 없어 Yousician 대체는 아니지만,
음성과학 근거·테크닉 계측(피치+포먼트+비브라토+셈여림+호흡)·훈련 게임 6종 전부 앱 내 탑재·습관화·성대 보호의 조합은 독자적 위치.

## 성종(聲種)·득음(得音) 리서치 요약
- **성종**: 타고난 음역·음색·성구전환 위치로 분류 (남: 테너/바리톤/베이스, 여: 소프라노/메조/알토).
  "성종을 알아야 득음이 쉽다"는 정확 — 자기 음역에 맞는 목표 설정이 부상을 막고 파사지오 훈련 방향을 정함.
- **득음**: 판소리에서 유래 ('성음을 얻음'). 현대 보컬에서는 흉성-중성-두성이 끊김 없이 이어진 완성 상태.
  앱의 3주차 파사지오 통과 훈련 + 스트릭(백일공부의 현대판)이 득음 로드맵에 직결.
