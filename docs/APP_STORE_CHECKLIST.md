하루보컬은 실시간으로 당신의 음정을 분석하고, 과학적 근거에 기반한 훈련으로 성장을 이끌는 iOS 보컬 트레이너입니다.

【주요 기능】
• 실시간 피치 분석 — YIN 알고리즘으로 ±12센트 정밀도
• 훈련 모드 9종 — 단음 유지(최장 발성 자동 측정) · 에코 3음 · 스케일 따라부르기(자체 합성 반주) · 말하기 피치 · 모음 게임 · 음정 게임 · 귀 훈련
• 테크닉 계측 — 비브라토 체크(속도·진폭·규칙성) · 셈여림 아치(메사 디 보체) — 내 목소리의 숫자를 처음으로 봅니다
• 오늘의 추천 훈련 — 취약점을 실측 데이터로 골라 탭 한 번으로 시작
• 4주 로드맵 — 힘빼기 → 가성 스위치 → 파사지오 → 실전
• 성종 추정 — 측정 음역 + 말하기 피치로 테너/바리톤/베이스 분류
• 스트릭 & 프리즈 — Duolingo식 습관 형성
• 성대 보호 — 목 아픈 날 자동으로 쉬는 날 루틴 전환

## 6. 스크린샷 캡처 가이드 + 문안 (2026-09-06)

6.7"(1290×2796)와 5.5"(1242×2208) 각각 캡처. 시뮬레이터 명령:
`xcrun simctl io "iPhone 16 Pro" screenshot <name>.png` — 조작 후 1초 대기 후 캡처.
(온보딩 각 페이지는 `simctl launch ... --onboarding-page N` 딥링크로 진입 —
CI smoke 워크플로가 이미 같은 방식으로 5페이지를 캡처 중.)

| # | 화면 | 진입 경로 | 캡션 문안 (상단 오버레이) |
|---|---|---|---|
| 1 | 온보딩 3p — 트래커 소개 | `--onboarding-page 2` | 음정부터 비브라토까지, 전부 측정됩니다 |
| 2 | 일일 루틴 | 온보딩 완료 → 첫 화면 | 하루 15분, 4주 로드맵이 알아서 진행돼요 |
| 3 | 피치 트래커 — 실시간 궤적 | 트래커 탭 → 단음 유지로 측정 중 캡처(가이드 톤 재생 직후) | 내 음정이 선으로 보입니다 |
| 4 | 비브라토 체크 결과 | 트래커 → 비브라토 체크 1회 완료 상태 | 비브라토 속도·진폭·규칙성까지 숫자로 |
| 5 | 셈여림 아치 결과 | 트래커 → 다이내믹스 아치 완료 상태 | 한 음으로 그리는 셈여림 아치 |
| 6 | 멜로디 따라부르기 | 트래커 → 멜로디 모드, 진행 중 | 들리고 부르고 — 프레이즈가 길어질수록 늘어요 |
| 7 | 성장 기록 — 오늘의 추천 | 성장 기록 탭(세션 2~3회 데이터 있는 상태) | 오늘 약한 훈련을 먼저 골라줍니다 |
| 8 | 테크닉 스냅샷 + 히트맵 | 성장 기록 탭 하단 | 연습이 쌓이는 게 눈에 보입니다 |

캡처 전제 조건: 4·5·7·8번은 시드 데이터 필요 — 개발 빌드에서 각 모드 1~2회
